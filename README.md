Momentum paper-trading bot for make.fun's Pump.fun Replay Sprint: it buys a bonding curve only once it shows broad, real buying flow (several distinct buyers, net SOL in, price up and near its recent high), starts at 0.05 SOL, holds for a full double or a trailing stop, one entry per mint, and paces small probe round trips to hold the 20-coin guardrail. Small stakes and low turnover on purpose — round-trip fees make churn lose.

## Run it

```sh
node main.ts
```
